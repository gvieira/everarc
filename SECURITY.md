# Security reports

Please report suspected security vulnerabilities privately to
[guilherme_vieira@me.com](mailto:guilherme_vieira@me.com), with
"Everarc security report" in the subject. Do not open a public issue or pull
request containing vulnerability details before coordinating disclosure.

Include the affected Everarc version, your operating system and browser when
relevant, reproduction steps, and the potential impact. Use a minimal synthetic
configuration or proof of concept; do not send personal financial reports,
credentials, or other sensitive data.

Everarc is an early-stage project. Security fixes focus on the latest release;
older releases have no guaranteed backports. There is no guaranteed response or
resolution timeline.

Ordinary bugs, including calculation errors without a security impact, belong
in [GitHub Issues](https://github.com/gvieira/everarc/issues). See
[CONTRIBUTING.md](CONTRIBUTING.md) for reporting guidance.
